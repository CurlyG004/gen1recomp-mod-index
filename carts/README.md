# Cart entries

One folder per cart, metadata only:

```
<Author>@<cart id>/
  meta.json          required, the entry itself
  description.md     required, long form markdown
  thumbnail.png      optional, or thumbnail.jpg, 2 MB max
```

Nothing else may live in the folder. Copy
[`examples/YourName@example_cart/`](../examples/YourName@example_cart) and read
[CONTRIBUTING.md](../CONTRIBUTING.md#submitting-a-cart).

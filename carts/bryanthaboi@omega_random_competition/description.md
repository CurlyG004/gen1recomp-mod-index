# OMEGA RANDOM COMPETITION

A maroon cartridge that plays as its own game. It ships one mod, the Bois Club
Randomizer, pinned to a version and sealed so every copy of this cart is the
same cart.

## The rules it enforces

- **One mod, sealed.** BCR at 1.0.0 and nothing else. The mod set cannot be
  added to, taken from, or switched off, so two people running this cart are
  running the same code.
- **1x or 2x only.** The speed ladder is pinned. There is no fast-forwarding
  past a bad encounter.
- **One seed per run**, taken from your player name and the clock at the moment
  you start. Two people who start with the same name at the same time get the
  same world; anyone else gets their own.

## What a run looks like

Wild species, ground items, shop stock, wild movesets and the three starters are
all rerolled. Every door outside Pallet Town leads somewhere new, and every one
of those doors is two-way, so what you walk into you can walk back out of.
Encounter levels are untouched, so the difficulty curve is still the one the
game shipped with.

Nothing tells you where a door goes. Take notes, or get lost.

## Before you enter it in anything

Seeds are not checked for completability. Paired doors mean you can never be
sealed into a room, and the world stays as connected as vanilla's, but an item
can still end up behind a door that needs that item. If a seed cannot be
finished, that is a dead seed and not a bug. For a competition, agree the seed
up front and make sure somebody has finished it.

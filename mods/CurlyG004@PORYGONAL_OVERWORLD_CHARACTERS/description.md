**Porygonal - Overworld Characters** replaces overworld character sprites with custom polygonal 3D models, bringing characters into the same 3D world as your voxel renderer.

Currently compatible with **Dramatic Shape**, **Dramaless Shape**, and **Potato Voxel**.

Porygonal supports overworld characters and special player states including walking, cycling, surfing, fishing, and Fly, with renderer-specific compatibility where required.

Supports **Pokémon Red, Blue, and Yellow** through Gen1Recomp.

Porygonal is designed as a graphics/content mod and does not intentionally alter gameplay, progression, battles, encounters, or link-relevant game data.

### Installation

Install the latest Porygonal release through Gen1Recomp's mod interface or import the release ZIP manually.

A supported 3D renderer must also be installed and enabled.

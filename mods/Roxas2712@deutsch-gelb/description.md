# Deutsch für Pokémon Gelb

Macht die importierte US-ROM in Gen1Recomp auf Deutsch spielbar. Dialoge,
Pokédex-Texte, Namen und Schriftzeichen stammen aus der deutschen
**Gelben Edition – Special Pikachu Edition** — nichts davon ist maschinell
übersetzt. Die sehr klein gesetzte Editionszeile wurde für Gen1Recomp
eindeutig lesbar neu gezeichnet.

- 2.695 originale deutsche Dialog- und Pokédextexte einschließlich aller
  Gelb-spezifischen Szenen
- originale deutsche Pokémon-, Attacken-, Item-, Trainer- und Typnamen
- originale Schrift mit Ä, Ö, Ü, ä, ö, ü und ß
- deutsche Titelgrafik mit klar lesbarem „GELBE EDITION“
- deutsche Kampftexte sowie Status- und Wertekürzel (GIF, ANGR, VERT, INIT, SPEZ)
- alle 151 Pokémon und 165 Attacken

Die Mod wird ausschließlich beim Start von Pokémon Gelb aktiv; Rot und Blau
bleiben unberührt.

## Installation

1. `deutsch-gelb-<version>.zip` von der
   [Releases-Seite](https://github.com/Roxas2712/pokemon-gelb-deutsch-mod/releases)
   herunterladen.
2. In Gen1Recomp: **MODS → Import mod .zip**.
3. Mod aktivieren und das Spiel neu starten.

Es wird weiterhin eine eigene, rechtmäßig erworbene US-ROM von Pokémon Gelb
benötigt; das Archiv enthält keine ROM und keine Spielstände.

> ENG: German translation of Pokémon Yellow, using original text, names and
> font from the German Gelbe Edition. Yellow-only, so it coexists with the
> author's Red and Blue mods.

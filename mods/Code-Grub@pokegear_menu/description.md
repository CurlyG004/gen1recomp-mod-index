# PokéGear Menu

Restyles the START menu as a handheld device: nine apps in a 3x3 grid, drawn
in colour over the live overworld, with a status bar, page dots and a
nameplate.

**It is a reskin of the menu, not the Gen 2 PokéGear.** The real PokéGear had
a clock, a map, a radio and a phone. This has the clock and the map. There is
no radio and there are no calls, and every app it shows is somewhere the START
menu already went.

## The apps

Dex, Pkmn, Bag, Id, Options and Save reach exactly what the START menu
reached. Two things differ:

- **Map** opens the TOWN MAP, and needs you to be carrying it, exactly as
  using the item from the bag does. Nothing becomes reachable that was not
  reachable before.
- **QUIT is gone.** A+B+SELECT+START performs the same return to the title
  from any state, on every platform, which is what QUIT called.

## Details

- **An app never moves.** Each one owns a fixed cell for the life of the save.
  One you have not earned yet sits dimmed in place rather than reflowing the
  grid, so what you learned in the first hour still holds in the last.
- **Other mods keep working.** A mod that inserts its own START menu row still
  gets its row. Those rows are kept off page one so they cannot shift the nine
  built-in apps, and they flow onto page two with the page dots.
- **The clock is real.** It shows system time, and the signal bars fill when a
  link session is live.
- **Saving is the engine's own.** The SAVE app opens the game's real save
  confirmation rather than a copy of it, so it behaves exactly as it always
  did, timing included.

## Art

Every pixel is generated by `tools/gen_assets.py`, which declares each icon and
glyph as text. Nothing in the package derives from a ROM, and neither does the
preview art.

## Install

Grab the release zip and import it: FIND MODS in the launcher, or drop the zip
into the save directory's `imports/mods/` folder and rescan.

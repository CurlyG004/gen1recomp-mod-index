Choose a permanent Trainer Path before Professor Oak's introduction and play Pokemon Red as one of twelve distinct trainer avatars.

Each path includes matching overworld, bicycle, fishing, portrait, and battle-back artwork. It also adds a path summary page, class-themed name suggestions, title-screen Pokemon, Gym statue records, and an optional themed Pokemon from Oak. Decline Oak's offer to choose one of the three original starters instead.

Available paths: Trainer Red, Dragon Tamer, Black Belt, Bug Catcher, Bird Keeper, Channeler, Fisherman, Hiker, Rocker, Psychic, Burglar, and Beauty.

A new game is required to choose a Trainer Path. This is an unofficial fan-made mod and is not affiliated with Nintendo, Game Freak, Creatures Inc., or The Pokemon Company.

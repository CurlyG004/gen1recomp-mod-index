# 0 EXP Challenge

0 EXP Challenge or No EXP Challenge is a challenge in Pokemon and other role-playing games where players aim to complete the game without leveling up or gaining experience, usually requiring the use of cheat codes or a modified ROM.
This simple mod enables you to play this challenge in gen1recomp by replacing all battle EXP gain with 0.

## Install

1. Download the .zip archive with the latest version of the mod from releases page.
2. In the launcher, open **MODS** tab and drag-and-drop the .zip with the mod onto the window or click on **Import mod .zip** and select the archive.

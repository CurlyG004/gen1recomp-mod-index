# PotatoVoxel (Beta)

PotatoVoxel is an unconditional Brick-mode 3D voxel overworld for the Gen 1 recomp engine, forked from Dramatic Shape and tuned for low-end devices.

It keeps the supported render-scale modes, mesh cache, and prebuild pipeline while providing Brick-only defaults. The release includes HIGH, MEDIUM, LOW, and POTATO modes, with HIGH using the two-layer 1536px shadow map and lower active modes using contact shadows.

# Booker's Heaven

Welcome to Booker's Heaven: a quest mod for the Gen 1 recomp.

Declares the `engine_internals` permission and runs as a `content` profile
mod, so link play is unaffected.

## Install

1. Download `bookers_heaven-1.1.0.zip` from the
   [releases page](https://github.com/bryanthaboi/bookers_heaven/releases).
2. In the launcher: MODS → **Import mod .zip**.

With `"github": "bryanthaboi/bookers_heaven"` set, the launcher's **Update**
and **Versions** buttons handle new releases from there.

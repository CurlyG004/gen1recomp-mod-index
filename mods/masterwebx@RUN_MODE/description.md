# Run Mode

Hold **B** to run on the overworld: bike-speed (or faster) steps while on
foot. During scripted NPC walks, NPCs match your run speed so you are not
left waiting.

Toggle RUN on/off and pick **HOLD** or **TOGGLE** mode from OPTIONS.

## Install

1. Download `RUN_MODE-1.1.8.zip` from the
   [releases page](https://github.com/masterwebx/gen1recomp-run-mode/releases).
2. In the launcher: MODS → **Import mod .zip**.

With `"github": "masterwebx/gen1recomp-run-mode"` set, the launcher's **Update**
and **Versions** buttons handle new releases from there.

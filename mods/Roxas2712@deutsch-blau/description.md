# Deutsch für Pokémon Blau

Macht die importierte US-ROM in Gen1Recomp auf Deutsch spielbar. Dialoge,
Pokédex-Texte, Namen, Schriftzeichen und die Titelgrafik stammen aus der
unveränderten deutschen **Blauen Edition** — nichts davon ist maschinell
übersetzt. Nur zusätzliche Gen1Recomp-Oberflächen, die es im Game-Boy-Original
nicht gibt, wurden separat übersetzt.

- 2.582 originale deutsche Dialog- und Pokédextexte
- originale deutsche Pokémon-, Attacken-, Item-, Trainer- und Typnamen
- originale Schrift mit Ä, Ö, Ü, ä, ö, ü und ß
- originale Titelgrafik „BLAUE EDITION“
- deutsche Kampftexte sowie Status- und Wertekürzel (GIF, ANGR, VERT, INIT, SPEZ)
- alle 151 Pokémon und 165 Attacken

Die Mod wird ausschließlich beim Start von Pokémon Blau aktiv; Rot und Gelb
bleiben unberührt.

## Installation

1. `deutsch-blau-<version>.zip` von der
   [Releases-Seite](https://github.com/Roxas2712/pokemon-blau-deutsch-mod/releases)
   herunterladen.
2. In Gen1Recomp: **MODS → Import mod .zip**.
3. Mod aktivieren und das Spiel neu starten.

Es wird weiterhin eine eigene, rechtmäßig erworbene US-ROM von Pokémon Blau
benötigt; das Archiv enthält keine ROM und keine Spielstände.

> ENG: German translation of Pokémon Blue, using original text, names, font and
> title graphic from the German Blaue Edition. Blue-only, so it coexists with

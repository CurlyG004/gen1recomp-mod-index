# VersãoVermelha

Brazilian Portuguese, ripped from the **Hyd~Traduções Pokémon Versão
Vermelha v1.3.1** IPS patch rather than translated by hand.

2796 strings register at boot. Everything unfilled falls through to English,
so the game is playable at every point along the way.

## Install

1. Download `versaovermelha-0.2.0.zip` from the
   [releases page](https://github.com/bryanthaboi/versaovermelha/releases).
2. In the launcher: MODS → **Import mod .zip**.

With `"github": "bryanthaboi/versaovermelha"` set, the launcher's **Update**
and **Versions** buttons handle new releases from there.

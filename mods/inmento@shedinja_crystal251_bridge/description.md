# Shedinja Crystal 251 Bridge

A **Red/Blue/Yellow-only** compatibility bridge for using **Shedinja 0.1.12+** alongside **Crystal 251 0.11.3+**.

Crystal 251 uses internal species indexes 1–251, including Shedinja’s standalone Gen 1 index 152 for Chikorita. This bridge reserves index **252** for Shedinja, keeps its visible National Dex number at **#292**, and supplies the split-stat and genderless metadata Crystal 251’s battle and summary systems need.

Install and enable core Shedinja, Crystal 251, and this bridge. Crystal 251 must have completed its required ROM import. The bridge does not run in Gold; use the separate Shedinja Expanded Bridge for the Gold/Expanded Species configuration.

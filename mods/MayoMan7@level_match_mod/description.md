# Level Match Mod

Level Match Mod scales trainer battles to the player's current team. When a
trainer battle starts, every enemy Pokemon is raised to at least the highest
level among the player's healthy party members.

## What it changes

- Trainer Pokemon scale up to match the player's strongest healthy Pokemon.
- Trainer Pokemon never scale down if they are already higher level.
- Wild encounters, player Pokemon, maps, items, and story progress are not changed.

## Install

1. Download `level_match_mod-0.1.0.zip` from the releases page.
2. In the launcher, open MODS and choose Import mod .zip.
3. Enable Level Match Mod and start or load a Gen 1 save.

With GitHub releases enabled, the launcher's Update and Versions buttons can
track future releases automatically.

## Compatibility

- Mod API 2.
- Supports Gen 1 games.
- Pure content-profile gameplay mod.
- No known dependencies or conflicts.

# Example Cart

One or two sentences on what the cart plays like. The first ordinary line
becomes the card blurb if `summary` is empty, so make it count.

## What is on it

| Mod | Build | Frozen options |
| --- | --- | --- |
| example_mod | 1.2.0 | hard difficulty, IVs shown |
| example_sprites | GameBanana file 987654 | defaults |

Loaded in that order: sprites first, so `example_mod` can draw over them.

## Playing it

1. Download `example_cart-1.0.0.zip` from the releases page.
2. In the launcher, CARTS -> **Import cart .zip**.
3. Pick it on the shelf and start a new game.

The cart is sealed, so it loads exactly those two mods and nothing else. Every
mod it names is published on its own and installed from its own source; the
cart itself is a manifest and label art.

## Compatibility

- Base game Red, engine `>=0.9`.
- Saves belong to the cart, not to your Red save file.
- Link play only matches another copy of this cart at the same version.
